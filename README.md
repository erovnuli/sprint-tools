# Sprint-tools

კონსოლური უტილიტები Sprint Layout -ის მოხმარებლებისათვის. შეიცავს შემდეგ კომპონენტებს:
lay2svg - სქემის გადაყვანა ვექტორულ ფორმატში 1:1 მასშტაბით, შრეების დაჯგუფებით და ფერების შერჩევით.
lay6_crossings - პოულობს ერთიდაიგივე სპილენძის შრეზე შეცდომით გადაკვეთილ ბილიკებს.
lay6_vias - გამოიყენება რთულ პლატებზე "ჩარჩენილი" გამოუყენებელი ვიასების საპოვნელად და მოსანიშნად.
kicad2sprint - ამ უტილიტით შეგიძლიათ კიკადის ბიბლიოთეკები ავტომატურად გადაიყვანოთ სპრინტის ბიბლიოთეკებში.
kpcb2sprint - ეს უტილიტა საშუალებას გაძლევთ კიკადის სქემები გარდაქმნათ სპრინტ ლეიაუტის სქემებში.
net2sprint - მარტივი ავტომატური ტრეისერი (პლატების დამხატავი) შეუძლია .netlist ფაილის მიხედვით (Ltspice, Kicad, EasyEDA) დახატოს პლატის ნახატი.
იმგვარად, რომ ბილიკებმა ერთმანეთი არ გადაკვეთოს, სქემა იყოს სწორი და პადებიც ერთმანეთს არ ედებოდეს.

Command-line utilities for **Sprint-Layout 6** boards (`.lay6`) and macros (`.LMK`):
check boards for mistakes, export them to SVG, and convert KiCad footprints, KiCad boards
and SPICE netlists into Sprint-Layout files (The basic auto-tracer for quick prototyping).
You can check examples/flasher.lay6`: which is generated by `net2sprint.py` from an LTspice netlist.
The parts are placed to keep crossings low and pad-to-pad tracks are already drawn, ready for routing by hand.

## Tools

| Tool | What it does |
|---|---|
| [`lay6svg.py`](#lay6svgpy--board-to-svg) | Board → SVG at exact 1:1 scale (for CorelDRAW, Inkscape, laser/printing) |
| [`lay6_crossings.py`](#lay6_crossingspy--tracks-crossing-by-mistake) | Finds copper tracks that cross each other (X-shaped shorts) |
| [`lay6_vias.py`](#lay6_viaspy--vias-connected-on-one-layer-only) | Finds vias that touch copper on only one layer |
| [`lay6_padcheck.py`](#lay6_padcheckpy--pad-to-pad-connection-rules) | Checks that pads of one kind connect to pads of another kind |
| [`kicad2sprint.py`](#kicad2sprintpy--kicad-footprints-to-sprint-macros) | KiCad footprints (`.kicad_mod` / `.pretty`) → Sprint macros (`.LMK`) |
| [`kpcb2sprint.py`](#kpcb2sprintpy--kicad-board-to-sprint-board) | KiCad board (`.kicad_pcb`) → Sprint board (`.lay6`) |
| [`net2sprint.py`](#net2sprintpy--netlist-to-sprint-board) | LTspice netlist → Sprint board with parts placed and tracks drawn |

`lay6.py` is the shared read/write library and `skel_font.py` makes single-stroke text from
a TrueType font. Neither is run directly.

**No tool changes your original file.** Results are always written to a new file.

## Installation

1. Install [Python](https://www.python.org/downloads/) 3.8 or newer.
2. Download this repository (green **Code** button → **Download ZIP**) and unpack it.
   Keep all `.py` files in one folder, because the tools load each other from there.
3. Only for text and labels in `kpcb2sprint.py` and `net2sprint.py`:
   ```
   pip install -r requirements.txt
   ```
   Everything else uses the Python standard library only.

Run any tool without arguments, or with `-h`, to see its full help.

Labels need a TrueType font. The tools look for, in order: the file named in the
`LAY6_FONT` environment variable, then `DejaVuSans.ttf` next to the scripts, then the usual
system fonts (DejaVu Sans on Linux, Arial on Windows and macOS).

### `lay6svg.py` – board to SVG

```
python lay6svg.py board.lay6 out.svg [options]
```

| Option | Meaning |
|---|---|
| `--layers LIST` | layers to include (default all): `c1 c2 i1 i2 s1 s2 o drill` |
| `--no-fill` | draw zones as outlines only |
| `--frame` | add the canvas border as a size reference |
| `--holes CSV` | also write every hole as `x;y;diameter;plated` (mm) |
| `--yup` | CSV only: Y measured upwards from the bottom edge |
| `--as-layers` | mark each Sprint layer as an SVG layer (CorelDRAW may lock them) |

Each Sprint layer becomes a plain, unlocked group. This script needs no other file.

```
python lay6svg.py board.lay6 board.svg --layers "c1 s1 o" --frame
```

### `lay6_crossings.py` – tracks crossing by mistake

```
python lay6_crossings.py board.lay6 [--mark OUT.lay6] [--all] [--tol MM]
```

Reports tracks on the same copper layer that cross as an **X**. T and L joints (a track
ending on another) are connections and are not reported.

| Option | Meaning |
|---|---|
| `--mark OUT.lay6` | write a copy with a ring (top silkscreen) at every crossing |
| `--all` | also list crossings between tracks already on the same net |
| `--tol MM` | how close to a track end still counts as a T joint (default 0.02) |

Exit code 2 when crossings are found, 0 when clean.

### `lay6_vias.py` – vias connected on one layer only

```
python lay6_vias.py board.lay6 [--via DRILL/OUTER] [--mark OUT.lay6] [options]
```

| Option | Meaning |
|---|---|
| `--via D/O` | via size in mm (default `0.4/0.7`) |
| `--tol MM` | size tolerance (default 0.01) |
| `--mark OUT.lay6` | write a copy with a ring around every single-layer via |
| `--mark-floating` | also ring vias that touch no copper at all |
| `--ring MM` | ring diameter (default 1.0) |
| `--ring-layer N` | ring layer: 2 = top silkscreen, 4 = bottom silkscreen (default 4) |

### `lay6_padcheck.py` – pad-to-pad connection rules

```
python lay6_padcheck.py board.lay6 --from KIND --to KIND [options]
python lay6_padcheck.py board.lay6 --list
```

Checks that every pad of one kind reaches pads of another kind through copper.
Pad kinds (sizes in mm, `*` = any):

| Kind | Meaning |
|---|---|
| `tht:1.0/2.0` | through-hole pad, drill/outer diameter (a via is a small through-hole pad) |
| `tht:1.0/*`, `tht:*/2.0` | any outer size / any drill |
| `smd:1.5x1.0` | SMD pad width × height, either orientation |
| `smd:*` | any SMD pad |

| Option | Meaning |
|---|---|
| `--list` | list the pad sizes found on the board and exit |
| `--from KIND` | pads to check |
| `--to KIND` | pads they must reach |
| `--min N` | at least N `--to` pads (default 1) |
| `--max N` | at most N `--to` pads (`--max 1` = exactly one) |
| `--shared` | also report `--to` pads that serve more than one `--from` pad |
| `--tol MM` | size tolerance (default 0.01) |
| `--mark OUT.lay6` | write a copy with the failing pads ringed |

```
python lay6_padcheck.py board.lay6 --from tht:1.0/2.0 --to tht:0.5/0.8 --max 1 --shared
```

### `kicad2sprint.py` – KiCad footprints to Sprint macros

```
python kicad2sprint.py INPUT OUTPUT_FOLDER [--board] [--no-back-silk]
```

`INPUT` is one `.kicad_mod` file or a whole `.pretty` folder. One `.LMK` macro is written
per footprint, and each footprint is reported as ok, skip or FAILED, with any approximations made.

| Option | Meaning |
|---|---|
| `--board` | also write a `.lay6` board per footprint (100 × 100 mm), for checking |
| `--no-back-silk` | leave out the back silkscreen |

```
python kicad2sprint.py Package_SO.pretty sprint_macros
```

### `kpcb2sprint.py` – KiCad board to Sprint board

```
python kpcb2sprint.py board.kicad_pcb out.lay6 [--no-text] [--no-zones] [--margin MM]
```

For KiCad 6 or newer.

| Option | Meaning |
|---|---|
| `--no-text` | leave out references and board text |
| `--no-zones` | leave out copper zones |
| `--margin MM` | space around the board outline (default 5) |

### `net2sprint.py` – netlist to Sprint board

```
python net2sprint.py NETLIST.net PARTS.txt out.lay6 [options]
```

Reads a netlist in ExpressPCB format (in LTspice, export the netlist in that format). It then:
- places the parts, moving and rotating them to reduce crossings;
- draws pad-to-pad tracks;
- moves tracks that must cross to the other layer, adding vias where needed.

With Sprint's *rubber band* function on, the tracks follow the parts when you drag them.

The parts file has one line per part; `#` starts a comment:

```
# REF  FOOTPRINT                             PINMAP (netlist pin = footprint pads)
Q*     fp/TO-92_Inline.kicad_mod             1=3 2=2 3=1
R*     TH2                                   # built in: two through-hole pads, 2.54 mm apart
U1     fp/SOIC-8_3.9x4.9mm_P1.27mm.kicad_mod
V1     -                                     # '-' leaves the part out
```

Without a pin map, netlist pin *n* goes to footprint pad *n*. Names ending in `*` match by prefix.

| Option | Meaning |
|---|---|
| `--width MM` | track width (default 0.3) |
| `--layer top\|bottom` | track layer |
| `--clearance MM` | minimum gap between a track and other copper (default 0.2) |
| `--via OUTER DRILL` | via size (default `0.7 0.4`) |
| `--no-vias` | keep every track on one layer |
| `--no-place` | keep the simple grid (no moving or rotating) |
| `--tries N`, `--iters N` | placement effort (default 4 attempts × 6000 steps) |
| `--segments` | one straight track per pad pair instead of polylines |

Try it with the example:

```
python net2sprint.py examples/flasher.net examples/flasher.parts flasher.lay6
```

## Notes and limits

- Tested with files from Sprint-Layout 6.0. Files from some other Sprint versions store an
  extra name string in every object; the tools read those too.
- Labels made by these tools are stored as finished strokes. They look right in Sprint, but
  if you open a label in Sprint's text dialog and press OK, Sprint redraws it with its own font.
